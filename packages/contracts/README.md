# Contracts

`app-manifest.schema.json` and `openapi.json` are generated by `python scripts/export_contracts.py`.
The Pydantic definitions in `backend/mediahub` are the source of truth. Regenerate after changes.
Frontend DTOs live in `frontend/src/contracts.ts`; Phase 1 keeps them explicit and verifies behavior
through browser integration tests. Automated OpenAPI-to-TypeScript generation is not yet implemented.

Only built-in adapters are allowed. These schemas do not grant runtime privileges.

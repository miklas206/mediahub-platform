# Independent app data in Overview

`GET /api/v1/app-overview` returns independent `mediaseed` and `mediavpn` entries, each with `status` (`ok`, `denied`, `not_configured`, `unavailable`) and successful `data`. One failing app does not suppress the other. The frontend refreshes every ten seconds while visible, discards data after failure and treats observations older than thirty seconds as unknown.

For each app the hub checks the current user's app role, then creates a server-only SSO grant with `scope: overview`, bound to that user's current hub session and app package, expiring within thirty seconds. It requests the app's `GET /api/hub/overview` over verified HTTPS without redirects and removes the grant in `finally`. Expired grants left by process termination are removed during the next mint. Requests have a twelve-second timeout and one MiB response limit. No browser app session, login cookie, integration key or browser-visible bearer token is created. Normal users can call the hub endpoint, but each app enforces current role/session validity through existing SSO introspection. Missing or ordinary unscoped SSO grants are rejected by the app endpoint.

MediaSeed reuses the authorized dashboard snapshot (up to 500 torrents, current VPN gate). The card shows active and queued downloads, seeding count, rates and up to three active progress rows. Configured tracker account statistics come from the existing five-minute cache/background worker; the overview never triggers tracker API requests. Only names, numeric statistics, status and observation time are exposed, without account URLs, usernames or API keys. Missing/stale tracker data is explicit.

MediaVPN reports up to 100 configured profiles with names, verified current countries, connection state and automatic-selection mode. The consumer list reflects its supported MediaSeed binding and separately reports whether that client is protected. This is not discovery of arbitrary Docker containers or unrelated VPN users. No private WireGuard configuration is returned. Overview requests never start/stop profiles or torrents.
